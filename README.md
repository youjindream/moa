# MOA

일정과 일기를 한곳에서 관리하는 개인 웹 프로젝트입니다. 캘린더에서 날짜별 일정을 확인하고, 홈 화면에서 오늘 할 일과 이번 주 일정 현황을 볼 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 회원가입 및 로그인 | 이메일로 회원가입하고 로그인할 수 있습니다. 비밀번호는 BCrypt로 해시한 뒤 저장합니다. |
| 일정 관리 | 일정을 등록·조회·수정·삭제할 수 있습니다. 일정에 시작·종료 시각, 종일 여부, 완료 상태, 라벨을 설정할 수 있습니다. |
| 일기 관리 | 날짜별로 일기를 작성하고 조회·수정·삭제할 수 있습니다. 홈 화면에서 오늘 작성한 일기를 확인할 수 있습니다. |
| 캘린더 | 연·월을 기준으로 한 달의 일정을 조회하거나, 선택한 날짜의 일정을 조회할 수 있습니다. |
| 홈 대시보드 | 오늘 일정과 일기, 다가오는 일정 최대 3개, 이번 주 일정 통계를 한 화면에서 확인할 수 있습니다. |

## 백엔드 구현

- **인증 및 사용자별 데이터 접근**  
  Spring Security로 로그인과 인증을 구현했습니다. 일정 상세 조회 시 로그인한 사용자와 일정 소유자가 일치하는지 확인합니다.

- **날짜 범위 기반 일정 조회**  
  월별·일별 조회 요청을 각각 시작·종료 시각으로 변환하고, Spring Data JPA를 사용해 해당 범위의 사용자 일정을 조회합니다.

- **홈 화면 데이터 집계**  
  `GET /home`에서 오늘 일정과 일기, 다가오는 일정, 주간 통계를 하나의 응답으로 반환합니다. 주간 통계에는 전체 일정 수, 완료한 일정 수, 요일별 일정 수를 담았습니다.

## 개발 범위

Spring Boot로 백엔드 API와 서비스 로직을 직접 구현하고, Spring Data JPA로 데이터베이스를 연동했습니다. React 화면은 생성형 AI로 생성한 코드를 활용했습니다.
