# MOA 프로젝트 개발 문서

## 1. 프로젝트 개요

### 프로젝트명

**MOA (모아)**

### 프로젝트 주제

**올인원 멀티미디어 스마트 플래너**

### 프로젝트 소개

MOA는 기존의 텍스트 중심 캘린더를 넘어 **일정, 일기, 할 일, 사진, 음성 등 다양한 기록을 하나의 플래너에서 관리할 수 있는 서비스**이다.

텍스트뿐만 아니라 이미지와 음성 등의 멀티미디어 기록을 지원하며, 향후 AI를 활용하여 이미지와 음성을 텍스트로 변환하고 핵심 내용을 자동으로 정리하는 기능까지 구현하는 것을 목표로 한다.

또한 하나의 계정을 기반으로 웹, 모바일, PC 등 여러 환경에서 동일한 데이터를 사용할 수 있는 멀티 플랫폼 서비스를 지향한다.

---

# 2. 개발 진행 기록

## Day 1 — 프로젝트 기획

달력 기반의 플래너 서비스를 개발하기로 결정하고 전체적인 서비스 방향과 주요 기능을 기획하였다.

단순한 일정 관리 기능에 그치지 않고 일정, 일기, 할 일, 사진, 음성 등을 한곳에서 관리할 수 있는 **올인원 플래너**를 목표로 설정하였다.

기획한 내용을 기반으로 AI를 활용한 프로토타입을 제작하면서 실제 화면에서 필요한 기능과 UI 구조를 확인하였다.

### 진행 내용

* 프로젝트 주제 선정
* 핵심 기능 아이디어 정리
* 멀티미디어 플래너 방향 설정
* AI를 활용한 초기 프로토타입 제작
* 필요한 기능 및 UI 구조 검토

---

## Day 2 — UI/UX 목업 및 Git/GitHub 환경 구축

프로젝트 기획 내용을 기반으로 **Figma를 이용하여 UI/UX 목업을 제작**하였다.

화면 구성을 시각적으로 구현하면서 캘린더를 중심으로 일정, 일기, 리마인더 등의 기능을 어떻게 배치할지 구체화하였다.

또한 기존에 Spring Boot 학습용으로 개발했던 SBB 프로젝트에 Git을 적용하였다.

로컬 프로젝트에서 `git init`을 통해 Git 저장소를 생성하고 GitHub 원격 저장소에 업로드한 뒤 협업자를 초대하여 프로젝트를 공유하였다.

이를 통해 기존에 이론적으로 학습했던 **형상관리 시스템 Git의 실제 사용 흐름**을 직접 경험하였다.

### 진행 내용

* Figma를 활용한 UI/UX 목업 제작
* 화면 구성 및 기능 배치 구체화
* 기존 SBB 프로젝트 Git 저장소 초기화
* GitHub 원격 저장소 연결
* 프로젝트 Commit / Push
* GitHub 협업자 초대 및 프로젝트 공유
* Git 기반 협업 환경 테스트

---

## Day 3 — 데이터베이스 설계 및 ERD 작성

기획한 기능을 실제 데이터 구조로 표현하기 위해 **dbdiagram을 활용하여 ERD(Entity Relationship Diagram)를 작성**하였다.

회원, 일정, 일기, 리마인더, 미디어 등의 데이터를 어떤 테이블로 관리할지 정의하고 각 데이터 사이의 관계를 설계하였다.

특히 일정 공유 기능을 추가하기 위해 사용자와 일정 사이의 관계를 고려하여 데이터베이스 구조를 설계하였다.

### 주요 설계 대상

* 사용자(User)
* 일정(Event)
* 일기(Diary)
* 할 일 / 리마인더(Reminder)
* 미디어(Media)
* 라벨(Label)
* 일정 공유(Event Share)

# 3. 핵심 가치

## 손쉬운 멀티미디어 기록

일반적인 텍스트 일정뿐만 아니라 사진, 영상, 음성 등 다양한 형태의 기록을 하나의 플래너에서 관리한다.

## AI 기반 자동 텍스트 변환

사진이나 문서를 분석하여 텍스트를 추출하고, 음성 녹음을 텍스트로 변환하여 일정이나 일기에 활용할 수 있도록 한다.

## 높은 자유도의 개인화

사용자가 직접 배경화면, 테마, 라벨 등을 설정하여 자신만의 플래너를 만들 수 있도록 한다.

## 멀티 플랫폼 연동

하나의 계정을 기반으로 웹, 모바일, PC 환경에서 동일한 데이터를 사용할 수 있도록 한다.

## 일정 공유

다른 사용자와 일정을 공유하여 개인 일정뿐만 아니라 친구, 가족 등과 함께 사용할 수 있는 플래너를 목표로 한다.

# 4. 주요 기능

## 4.1 달력 및 일정 관리

연간, 월간, 주간, 일간 단위로 일정을 확인할 수 있도록 한다.

### 주요 기능

* Year View
* Month View
* Week View
* Day View
* 일정 등록 / 조회 / 수정 / 삭제
* 일정 반복 설정
* 일정 알림
* 일정 라벨 지정
* 대표 일정 표시

---

## 4.2 친구와 일정 공유

사용자가 자신의 일정을 다른 사용자와 공유할 수 있도록 한다.

### 주요 기능

* 사용자 검색
* 일정 공유
* 공유 사용자 목록 관리
* 공유 일정 조회
* 공유 취소

향후에는 공유된 일정에 대한 수정 권한을 구분하여 **조회 전용 / 공동 수정** 등의 권한을 추가할 수 있다.

---

## 4.3 한 줄 일기

하루에 대한 간단한 기록을 남길 수 있는 기능이다.

### 주요 기능

* 날짜별 한 줄 일기 작성
* 일기 수정 / 삭제
* 달력에서 일기 표시
* 과거 일기 검색
* 사진 및 미디어 첨부

---

## 4.4 멀티미디어 기록

텍스트뿐만 아니라 다양한 형태의 데이터를 일정이나 일기에 첨부할 수 있도록 한다.

### 지원 데이터

* 이미지
* 동영상
* 음성 녹음

---

## 4.5 AI 스마트 변환

멀티미디어 데이터를 AI가 분석하여 사용자가 직접 입력해야 하는 작업을 줄인다.

### 이미지

이미지나 문서 사진에서 텍스트를 인식하여 일정 또는 일기 작성에 활용한다.

예시:

영수증 사진 → 날짜 및 내용 추출

포스터 사진 → 행사명, 날짜, 장소 추출

메모 사진 → 텍스트 변환

### 음성

녹음된 음성을 STT(Speech-to-Text)를 이용하여 텍스트로 변환하고 핵심 내용을 요약한다.

---

## 4.6 리마인더 및 빠른 입력

일정 작성 과정에서 할 일을 빠르게 등록할 수 있도록 한다.

특정 입력 규칙을 활용하여 일반 텍스트와 할 일을 구분한다.

예시:

`・SQLD 공부하기`

위와 같이 입력하면 해당 내용을 자동으로 리마인더로 등록한다.

### 주요 기능

* 불릿(`・`) 기반 리마인더 자동 인식
* 완료 체크
* 완료 항목 취소선 표시
* 일정과 리마인더 연결

---

## 4.7 통합 검색

플래너에 저장된 다양한 데이터를 하나의 검색 기능으로 조회할 수 있도록 한다.

### 검색 대상

* 일정 제목
* 일정 내용
* 일기
* 라벨
* 리마인더

단어 및 초성 기반 검색 기능도 고려한다.

---

## 4.8 필터링

달력에 표시되는 데이터를 사용자가 직접 선택할 수 있도록 한다.

예시:

* 일정만 보기
* 일기만 보기
* 리마인더만 보기
* 공유 일정 보기

여러 필터를 조합하여 필요한 정보만 표시할 수 있도록 설계한다.

---

## 4.9 개인화

사용자가 자신의 취향에 맞게 플래너 화면을 변경할 수 있도록 한다.

### 주요 기능

* 사용자 이미지 배경화면 설정
* 색상 배경 설정
* 그라데이션 배경 설정
* 다크 모드
* 라이트 모드
* 일정 라벨 색상 설정

# 5. 멀티 플랫폼 구성

하나의 계정과 서버를 기반으로 여러 플랫폼에서 동일한 데이터를 사용할 수 있도록 하는 것을 장기적인 목표로 한다.

| 플랫폼    | 형태              | 주요 특징         |
| ------ | --------------- | ------------- |
| Web    | 웹 서비스           | 브라우저에서 바로 사용  |
| Mobile | Android / iOS 앱 | 촬영, 녹음, 푸시 알림 |
| PC     | 설치형 프로그램        | 데스크톱 접근 및 알림  |

모든 플랫폼은 동일한 백엔드 API와 데이터베이스를 사용하여 데이터를 동기화하는 구조를 목표로 한다.

# 8. 프로젝트 최종 목표

MOA 프로젝트의 목표는 단순히 달력을 구현하는 것이 아니라 **실제 사용 가능한 하나의 서비스를 기획하고 설계하여 완성하는 과정 전체를 경험하는 것**이다.

기획 → UI/UX 설계 → ERD 및 데이터베이스 설계 → 백엔드 개발 → 프론트엔드 개발 → Git 협업 → 배포까지의 전체 개발 과정을 직접 경험한다.

최종적으로는 일정, 일기, 할 일, 멀티미디어 기록과 일정 공유 기능을 하나의 서비스로 통합한 **개인화 스마트 플래너**를 완성하는 것을 목표로 한다.
